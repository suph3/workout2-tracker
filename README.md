# 🏋️‍♂️ Daily Workout & Weight Tracker

A mobile-friendly web application to track daily body weight progress and workout sessions across multiple muscle categories. Built using pure HTML5, CSS3, and JavaScript with cross-device sync (Username + PIN passcode authentication).

## 🚀 Features

- **Device Sync (No Email Mandatory)**: Register or login with a Username & 4-Digit PIN. Export/import sync codes to switch between phone and tablet seamlessly.
- **Multi-Category Daily Logging**: Log exercises across multiple muscle groups (Chest, Back, Abs, Biceps, Triceps, Legs, Cardio) on a single day.
- **Pre-populated & Custom Exercises**: Complete default exercise database with dynamic custom exercise creation.
- **Weight & Cardio Metrics**: Tracks Weight, Sets, Reps or Distance, Pace, Calories.
- **Interactive Analytics**: Body weight trend charts and muscle volume breakdown.
- **Rest Timer**: Built-in rest timer with celebration animations.

## 📂 File Structure

- `index.html` — Application layout and screens
- `style.css` — Modern glassmorphism CSS design system
- `app.js` — Core application logic, storage, & UI interactions
- `schema.sql` — Database table schemas
- `README.md` — Project documentation
